📱 앱 소개

소방점검관리사 앱은 소방 안전 점검을 효율적으로 수행하고 관리할 수 있는 모바일 애플리케이션입니다. 실시간 점검, 사진 첨부, 보고서 생성 등 소방점검 업무를 디지털화하여 생산성을 향상시킵니다.

🚀 시작하기

1. 앱 설치 및 실행

  1. 앱을 다운로드하여 설치합니다
  2. 앱을 실행하면 로그인 화면이 표시됩니다
  3. 계정이 없으신 경우 회원가입을 진행합니다

2. 회원가입

  1. 로그인 화면에서 "회원가입" 버튼을 클릭합니다
  2. 다음 정보를 입력합니다:
    • 이름
    • 이메일 주소
    • 비밀번호 (6자 이상)
    • 비밀번호 확인
  3. "회원가입" 버튼을 클릭하여 계정을 생성합니다
  4. 회원가입이 완료되면 자동으로 홈 화면으로 이동합니다

3. 로그인

  1. 로그인 화면에서 이메일과 비밀번호를 입력합니다
  2. "로그인" 버튼을 클릭합니다
  3. 로그인 성공 시 홈 화면으로 이동합니다

🏠 홈 화면

홈 화면은 앱의 메인 대시보드로, 주요 기능에 빠르게 접근할 수 있습니다.

주요 섹션

1. 환영 메시지

앱 상단에 환영 메시지가 표시됩니다: "안녕하세요, 오늘도 안전한 점검 되세요"

2. 빠른 작업

점검 시작

새로운 소방 안전 점검을 시작합니다. 체크리스트를 통해 점검 항목을 확인하고 기록합니다.

일정 확인

예정된 점검 일정을 확인합니다. 캘린더를 통해 날짜별 점검 일정을 관리합니다.

보고서

완료된 점검 보고서를 조회하고 생성합니다. PDF 형식으로 보고서를 내보낼 수 있습니다.

법령 조회

소방 관련 법령을 검색하고 조회합니다. 최신 법령 정보를 확인할 수 있습니다.

3. 오늘의 통계

오늘 수행한 점검 현황을 한눈에 확인할 수 있습니다:

  • 완료된 점검: 오늘 완료한 점검 건수
  • 진행 중: 현재 진행 중인 점검 건수
  • 불량 발견: 점검 중 발견한 불량 건수

4. 최근 점검 내역

최근에 수행한 점검 내역을 확인할 수 있습니다. "전체 보기" 버튼을 클릭하면 전체 점검 내역을 조회할 수 있습니다.

하단 네비게이션 바

화면 하단에 4개의 주요 메뉴가 있습니다:

  • 홈: 홈 화면으로 이동
  • 일정: 일정 관리 화면으로 이동
  • 보고서: 보고서 화면으로 이동
  • 설정: 앱 설정 화면으로 이동

✅ 점검 시작하기

1. 점검 화면 접근

  • 홈 화면의 "점검 시작" 버튼을 클릭합니다
  • 또는 하단 네비게이션 바에서 "홈" 메뉴를 선택한 후 "점검 시작"을 클릭합니다

2. 점검 항목 확인

점검 화면에는 다음과 같은 기본 점검 항목들이 표시됩니다:

소화기 점검

  • 소화기: 위치 표시
  • 소화기: 압력 게이지
  • 소화기: 안전핀 상태

옥내소화전 점검

  • 옥내소화전: 호스 상태
  • 옥내소화전: 밸브 개폐
  • 옥내소화전: 방수압

자동화재탐지 점검

  • 자동화재탐지: 감지기 상태
  • 자동화재탐지: 수신기 표시등

스프링클러 점검

  • 스프링클러: 헤드 상태
  • 스프링클러: 배관 압력
  • 스프링클러: 물공급

3. 점검 상태 선택

각 점검 항목에 대해 다음 상태 중 하나를 선택합니다:

정상 불량 해당없음

4. 사진 첨부

  1. "촬영" 버튼을 클릭하여 카메라로 직접 촬영
  2. "갤러리" 버튼을 클릭하여 기존 사진 선택
  3. 첨부된 사진은 항목 아래에 표시됩니다
  4. 사진을 삭제하려면 사진 우측 상단의 X 버튼을 클릭합니다

5. 메모 작성

각 점검 항목에 대한 메모를 작성할 수 있습니다. 특이사항, 보수 필요 사항 등을 기록할 수 있습니다.

6. 진행 상황 확인

화면 상단의 진행 바를 통해 점검 진행률을 확인할 수 있습니다: 완료된 항목 수 / 전체 항목 수

7. 임시 저장

점검 중간에 상단 우측의 저장 아이콘을 클릭하여 임시 저장할 수 있습니다. 저장된 점검은 나중에 이어서 진행할 수 있습니다.

8. 점검 완료

  1. 모든 항목의 상태를 확인합니다
  2. 필요한 사진과 메모를 첨부합니다
  3. 점검 완료 버튼을 클릭하여 점검을 마무리합니다

📅 일정 관리

일정 확인

  1. 홈 화면의 "일정 확인" 버튼을 클릭합니다
  2. 또는 하단 네비게이션 바에서 "일정" 메뉴를 선택합니다
  3. 캘린더에서 예정된 점검 일정을 확인할 수 있습니다

일정 추가

  1. 일정 화면에서 날짜를 선택합니다
  2. "일정 추가" 버튼을 클릭합니다
  3. 점검 정보를 입력합니다:
    • 건물 정보
    • 점검 시간
    • 점검 유형
  4. "저장" 버튼을 클릭합니다

📄 보고서

보고서 조회

  1. 홈 화면의 "보고서" 버튼을 클릭합니다
  2. 또는 하단 네비게이션 바에서 "보고서" 메뉴를 선택합니다
  3. 완료된 점검 보고서 목록이 표시됩니다

보고서 생성

  1. 보고서 화면에서 점검을 선택합니다
  2. 보고서 상세 정보를 확인합니다
  3. "PDF 내보내기" 버튼을 클릭하여 PDF 파일로 저장할 수 있습니다

보고서 내용

보고서에는 다음 정보가 포함됩니다:

  • 점검 일시
  • 건물 정보
  • 점검 항목별 상태
  • 첨부된 사진
  • 메모 내용
  • 점검자 정보

⚖️ 법령 조회

법령 검색

  1. 홈 화면의 "법령 조회" 버튼을 클릭합니다
  2. 검색창에 키워드를 입력합니다
  3. 관련 법령이 표시됩니다

법령 상세 보기

  1. 법령 목록에서 원하는 법령을 선택합니다
  2. 법령의 상세 내용을 확인할 수 있습니다
  3. 최신 법령 업데이트 정보도 확인할 수 있습니다

⚙️ 설정

설정 화면 접근

  • 홈 화면 상단 우측의 설정 아이콘을 클릭합니다
  • 또는 하단 네비게이션 바에서 "설정" 메뉴를 선택합니다

알림 설정

푸시 알림

앱 알림을 받을지 여부를 설정합니다. 켜기/끄기 토글을 사용합니다.

법령 업데이트 알림

법령 변경사항 알림을 받을지 여부를 설정합니다. 켜기/끄기 토글을 사용합니다.

백업 설정

Wi-Fi에서만 백업

모바일 데이터 사용을 줄이기 위해 Wi-Fi 연결 시에만 백업하도록 설정합니다.

수동 백업

"수동 백업" 버튼을 클릭하여 지금 바로 데이터를 백업합니다. 백업 중에는 로딩 인디케이터가 표시됩니다.

계정 관리

프로필 수정

이름, 이메일 등 개인정보를 변경할 수 있습니다.

비밀번호 변경

현재 비밀번호를 변경할 수 있습니다.

로그아웃

  1. "로그아웃" 버튼을 클릭합니다
  2. 확인 다이얼로그에서 "로그아웃"을 선택합니다
  3. 로그인 화면으로 돌아갑니다

앱 정보

  • 버전 정보: 현재 앱 버전을 확인할 수 있습니다
  • 이용약관: 서비스 이용약관을 확인할 수 있습니다
  • 개인정보 처리방침: 개인정보 처리방침을 확인할 수 있습니다

💡 사용 팁

1. 오프라인 사용

앱은 오프라인에서도 사용할 수 있습니다. 점검 데이터는 로컬에 저장되며, 인터넷 연결 시 자동으로 동기화됩니다.

2. 사진 품질

점검 사진은 최소 1080p 품질로 촬영하는 것을 권장합니다. 명확한 사진은 보고서 작성 시 유용합니다.

3. 정기 백업

중요한 점검 데이터는 정기적으로 백업하는 것을 권장합니다. 설정에서 Wi-Fi 연결 시 자동 백업을 활성화할 수 있습니다.

4. GPS 위치

점검 시 GPS 위치 정보가 자동으로 기록됩니다. 위치 정보는 점검 보고서에 포함됩니다.

5. 빠른 작업

홈 화면의 빠른 작업 버튼을 활용하여 자주 사용하는 기능에 빠르게 접근할 수 있습니다.

❓ 자주 묻는 질문 (FAQ)

Q1. 점검 중 앱이 종료되면 어떻게 되나요?

A: 점검 중간에 임시 저장 기능을 사용하면 데이터가 보존됩니다. 앱을 다시 실행하여 이어서 진행할 수 있습니다.

Q2. 사진은 몇 장까지 첨부할 수 있나요?

A: 각 점검 항목당 여러 장의 사진을 첨부할 수 있습니다. 다만, 앱 성능을 위해 과도한 사진 첨부는 권장하지 않습니다.

Q3. 오프라인에서 점검한 데이터는 언제 동기화되나요?

A: 인터넷 연결이 되면 자동으로 동기화됩니다. 수동으로 동기화하려면 설정에서 수동 백업을 실행하세요.

Q4. 보고서를 다른 형식으로 내보낼 수 있나요?

A: 현재는 PDF 형식만 지원합니다. 향후 업데이트에서 다른 형식도 지원할 예정입니다.

Q5. 여러 건물을 한 번에 점검할 수 있나요?

A: 각 건물별로 별도의 점검을 생성해야 합니다. 점검 화면에서 건물을 선택하여 점검을 시작할 수 있습니다.
